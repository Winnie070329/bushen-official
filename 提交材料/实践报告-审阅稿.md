## 一、实践背景

计算机学院 2026 年暑期社会实践「AI智行」主题，鼓励同学们把课堂所学落到真实场景，完成从需求分析、方案设计到作品交付的完整过程。参考选题「我用AI从零完成××项目」全流程日志，要求记录一个可展示、可复盘的项目成长轨迹。我选择以企业官网建设为实践载体，在数智化传播背景下，尝试为实体企业设计并落地一套结构清晰、视觉统一、可在线访问的展示型网站。

项目对象是佛山市顺德区布神家居用品有限公司（品牌：布神纺织 BUSHEN WEAVING）。公司成立于 2012 年，扎根顺德龙江家居产业带，主营窗帘布艺、床垫面料与纺织家纺，并运营微信视频号「布神织造」。实践启动前，我主动联系公司总经理，说明暑期实践意向与官网建设设想。对方表示：企业有实体经营与新媒体渠道，但缺少一个信息完整、形象专业、手机端也好用的官网入口；若能把展厅气质、产品品类和咨询通道做好，对公司对外展示很有帮助，并愿意就需求持续沟通、配合确认内容与方向。

这次沟通让我意识到：官网不是「随便做几个页面」，而是要把企业真实经营逻辑转成可浏览、可信任、可转化的线上体验。于是我将实践目标定为——在与总经理持续沟通需求的前提下，从零完成布神纺织企业官网的**整体设计与落地**。对我而言，重点不在「代码量多少」，而在「设计是否贴合需求、架构是否站得住、版本是否一步步变好」。这也是我本次成长的主线。

## 三、主要内容

### （一）听清需求，先做设计：从口头诉求到信息架构

实践初期，我没有急于动手写页面，而是先与总经理沟通，再完成需求梳理与整体设计。对方的诉求起初并不「结构化」，更像几句经营经验：

- 「客户最关心窗帘和床垫面料，品类一定要突出。」  
- 「要有展厅照片，让人感觉我们是真做布艺的，不是空壳公司。」  
- 「很多人会问能不能打样、起订多少、多久交货，最好网站上先答一半。」  
- 「地址、地图、视频号都要放出来，方便到访和继续聊。」  
- 「手机打开要好用，很多客户是微信里点链接。」  

我把这些口头诉求转写成设计问题：用户从哪进来？先看什么？如何建立信任？最后如何留资或到访？据此画出客户路径：**了解品牌 → 浏览展厅与产品 → 对照应用场景 → 建立信任 → 发起咨询 → 找到联系方式**。

第一版设计方案比较保守，只有「首页、关于、业务、联系」四板块。发给总经理后，对方反馈很直接：结构太薄，像模板站，看不出布神的业务厚度。于是我重新做信息架构，把网站设计为一条完整叙事链：

- **品牌首屏**：轮播展厅与面料实拍，先建立行业第一印象  
- **关于与发展**：公司定位 + 时间线，讲清「从哪来」  
- **官方展示**：大图 + 缩略图 + 放大查看，解决「看得见货」  
- **产品体系**：窗帘布艺 / 床垫面料 / 多色面料分类，贴合主营  
- **应用案例**：家装、酒店、公寓，回答「能用在哪」  
- **业务范围**：销售、供应、定制三类服务边界  
- **信任背书**：展会形象 + 视频号，打通线上线下  
- **服务支持**：FAQ + 在线咨询，降低沟通成本  
- **联系转化**：电话、邮箱、地址复制、地图导航  

**这一步的进步：** 我开始从「做一个网页」转向「做一套贴合业务的设计方案」。学会把零散需求翻译成模块、路径和优先级，并拿回去确认，而不是自己觉得好看就算数。

### （二）视觉与交互设计：让官网「像这家公司」，而不是「像任意模板」

架构确认后，我进入视觉与交互设计。总经理多次强调「要像纺织企业，不要太互联网风」。据此，我做了几项关键设计决策：

**1. 品牌气质设计**  
选用偏稳重的深蓝主色，搭配金色点缀，突出「专业、可信」；标题区强化「布神纺织」品牌名，副文案直接写「窗帘布艺 · 床垫面料 · 纺织家纺」，让客户三秒内知道公司做什么。

**2. 内容真实感设计**  
首屏与展示区优先使用展厅、面料样品、色卡、织带等实拍图，而不是抽象装饰图。官方展示做成「主图浏览 + 缩略图切换 + 进度条」，交互上贴近「在展厅里一张张看样品」的体验。

**3. 转化路径设计**  
页面中部保留咨询入口，底部联系区提供复制地址、高德/百度导航、视频号二维码。设计目标不是堆功能，而是让客户从「看懂」顺利走到「能联系」。

**4. 移动优先体验**  
针对「手机打开」这一强需求，设计折叠导航、触控友好的按钮尺寸，以及返回顶部等细节，避免内容挤成一团。

首版落地后，页面能打开，但总经理反馈：「信息还不全，图片不够像展厅，导航也偏少。」我没有停在「能用」，而是按设计清单继续贴合需求：补全公司全称与品牌英文名、替换空泛文案、扩展导航至完整板块、强化产品分类与图注说明。

**这一步的进步：** 我意识到好的设计不是「装饰漂亮」，而是「每一处都服务于需求」。颜色、图片、按钮、导航，都要能回答业务方那几句关键话。

### （三）多轮迭代：在沟通中不断改，在改中不断进步

真正让项目质量上台阶的，是持续沟通带来的多轮迭代。我把过程概括为「三版跃迁」：

#### 第一版：能看，但不像

- **状态：** 基础单页结构跑通，有导航、首屏、关于、业务、联系。  
- **问题：** 文案偏空、图片弱、品类不突出、缺少咨询与地图。  
- **总经理反馈：** 「像通用模板，看不出布神。」  
- **我的调整方向：** 先补真实信息与行业图片，再谈花哨效果。  

#### 第二版：像了，但还不够好用

- **状态：** 加入展厅实拍、产品分类、发展历程、信任背书。  
- **问题：** 产品不好筛选、细节图看不清、手机端体验一般、咨询入口弱。  
- **总经理反馈：** 「品类要能分开看；客户常问打样和交货；手机要好用。」  
- **我的调整方向：** 加 Tab 筛选、灯箱放大、FAQ、表单校验、移动端菜单优化。  

#### 第三版：贴合需求，形成可交付体验

- **状态：** 首屏轮播、官方展示、产品筛选、应用案例、FAQ、在线咨询、地图导航、视频号露出全部打通。  
- **确认结果：** 总经理认可「结构清楚、能代表公司、方便转发客户看」。  
- **我的收获：** 设计不是一次定稿，而是在反馈里不断逼近真实需求。  

各模块如何贴合沟通诉求，整理如下：

| 模块 | 总经理沟通中的需求 | 我的设计与实现 | 迭代后的改进 |
|------|--------------------|----------------|--------------|
| 首屏轮播 | 首屏要有展厅氛围 | 多图轮播 + 品牌主标题 | 从静态背景改为可感知的品牌场 |
| 官方展示 | 要让客户看得见货 | 主图 + 缩略图 + 放大 | 从「有图」升级到「好浏览」 |
| 产品展示 | 品类要突出、能分开看 | 分类 Tab + 产品卡片 | 从混排列表改为可筛选体系 |
| 应用案例 | 说明能用在哪些场景 | 家装 / 酒店 / 公寓对照 | 从自说自话变为场景化表达 |
| 常见问题 | 打样、起订、交货常被问 | FAQ 折叠答疑 | 把重复咨询前置消化 |
| 在线咨询 | 要有留资入口 | 表单校验 + 成功提示 | 从「放个联系方式」到「可行动」 |
| 联系地图 | 地址要能到 | 复制地址 + 双地图导航 | 从文字地址升级为到访路径 |
| 视频号 | 「布神织造」要露出 | 二维码 + 文案引导 | 官网与新媒体形成闭环 |

开发中也遇到具体问题：移动端菜单遮挡内容、轮播切换状态不同步、表单提交反馈不明显等。我通过浏览器开发者工具逐项排查，修正后再把新版本发给总经理确认。每一次确认，都让设计离「对方真正要的官网」更近一步。

**这一步的进步：** 从「自己觉得差不多」进步到「能听懂反馈、能改设计、能验证是否贴合需求」。进步不是抽象口号，而是版本上看得见的变化。

### （四）工程交付：把设计结果变成可访问作品

功能与体验基本贴合需求后，我完成工程化收尾，并把线上地址发给总经理做最终确认：

1. 使用 Git 管理版本，保留迭代过程，避免改乱后无法回退；  
2. 配置 GitHub Pages，获得可稳定转发的公网链接；  
3. 在电脑与手机分别检查导航、图片、表单、地图与视频号入口；  
4. 整理 README，说明项目结构与访问方式，方便后续维护说明。  

此前我的练习作品多停留在本地文件夹；这次完整走通了「沟通需求 → 设计架构 → 落地实现 → 多轮确认 → 线上发布 → 业务方验收」的交付链路。总经理确认后，网站可以作为对外展示与客户转发的入口。

## 五、总结体会

回顾整段实践，我最大的收获是建立了「需求驱动设计、设计驱动落地、反馈驱动进步」的意识。

第一，贴合需求比追求炫技更重要。与总经理的多轮沟通，逼着我不断问自己：这一块是为了好看，还是为了解决对方真正在意的问题？当首屏、展厅、品类、FAQ、地图都一一对应到具体诉求时，网站才真正「像布神」。

第二，设计能力体现在取舍与组织上。同样是做官网，四板块模板和完整叙事链差别很大。我学会了用客户路径组织内容，用视觉强化行业气质，用交互降低咨询成本——这些都属于设计决策，而不只是页面装饰。

第三，进步是看得见的。从第一版「能看但不像」，到第二版「像了但不好用」，再到第三版「贴合需求可交付」，每一次回传确认都让方案更接近业务真实。项目完成不等于个人包办一切：我查阅文档、参考同类实现、反复调试，并始终以沟通确认的需求为准绳。我负责的是整体设计、架构规划、迭代推进与最终交付——这正是本次实践最想记录的成长。

第四，社会实践要落在「做得到、说得清、拿得出」上。在与布神有限公司总经理持续沟通的前提下，从零设计并完成企业官网，让我第一次完整经历真实协作中的需求对齐与版本进步。这对今后课程设计、实习项目或小型开发任务，都是可迁移的经验。

青春筑梦，不必从远方开始。把一个家乡企业的官网从沟通与设计，一步步做到线上可访问、对方认可，同样是数智赋能、服务实体的一步。
